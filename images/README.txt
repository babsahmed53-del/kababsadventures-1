IMAGE FOLDER

The starter website currently uses remote demo photographs from images.unsplash.com.
To use your own KaBabs Adventures photos:
1. Save compressed JPG or WebP images in this folder.
2. Change the image URL in js/script.js (trip images) or the relevant HTML file (hero/gallery images).
3. Use descriptive alt text for accessibility.
4. Aim for images under about 300 KB where practical; use landscape images around 1600 x 900 px for banners.

Use photos you own or have permission to publish. Replace illustrative gallery and testimonial content with genuine brand material before launch.
